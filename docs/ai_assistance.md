# AI Assistance Disclosure

The 2026 public reconstruction received material assistance from OpenAI Codex.

The assistance included research-architecture suggestions, Python implementation, tests, generated-report logic, documentation and wording revisions. Public data adapters and third-party Python libraries also perform substantial work.

Repository ownership does not by itself establish unaided authorship. Anyone presenting this project should distinguish:

- what they personally specified before generation;
- what they personally reviewed and changed;
- which tests and reruns they personally executed;
- which formulas and code paths they can independently explain;
- what was generated or suggested by AI and libraries.

A defensible interview answer is:

> I used AI coding assistance in the public reconstruction. I do not claim unaided line-by-line authorship. I reviewed the architecture, formulas, timing controls, tests and generated results, and I can reproduce and critique the system. I distinguish this later public project from verified internship work.

This answer should be used only if the presenter has actually completed the stated review and can demonstrate it. The first-person handbook is intended to support that review; reading or memorizing it is not a substitute for running the code and understanding the outputs.
